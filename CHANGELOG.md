# Changelog

## 0.1.0 (2026-10-27)

- Initial release: `diff_api_surface` MCP tool and `diff`
  CLI command comparing the public API surface of two
  versions.
- Removed and added exports, kind changes, signature
  changes, member removals and additions, and deprecation
  changes, split into breaking and non-breaking lists
  sorted by name then change, with a summary and a
  breaking / clean verdict, and path-naming validation
  errors that name the side and the offending path.
